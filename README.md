⚙️ Backend Setup

Prerequisites

* Java JDK
* Maven
* MySQL Server

Run the Backend

1. Clone the repository.
2. Create and configure your MySQL database.
3. Update your database credentials using local configuration or environment variables.
4. Open a terminal in the backend directory.
5. Run:

mvn spring-boot:run

🗄️ Database Configuration

Configure the MySQL connection in your local Spring Boot configuration.

Do not publish database passwords, JWT secrets, or other sensitive credentials.
